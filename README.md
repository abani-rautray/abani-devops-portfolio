## Run Locally

This is a static website built as a standalone HTML file. No framework,
package installation, or build process is required.

1.  Clone the repository:

    ``` bash
    git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
    ```

2.  Open the repository folder.

3.  Open `index.html` in a web browser.

## Deploy on Vercel

1.  Push this repository to GitHub.
2.  Sign in to [Vercel](https://vercel.com/) with your GitHub account.
3.  Select **Add New → Project** and import this repository.
4.  Select **Other** as the framework preset.
5.  Leave the build command and output directory empty.
6.  Deploy.

Vercel will host the static website and provide a deployment URL. Future
pushes to the connected branch can trigger automatic deployments.
